# Round 04 Agent rules — B1-2

1. 신규 미션 코드: `training/round-04-agent/04-src/`만 사용. 계획·테스트·증빙·평가·슬라이드는 형제 폴더에 작성.
2. 기존 Repository Root와 이전 Round 자료는 변경·이동·삭제 금지; 읽기·근거 조회만 허용.
3. 승인 전 미션 소스 작성, 실행, 배포, 병합 금지. 현재 파일은 작업 경로 설정 문서임.
4. 공식 요구사항 → 소스 → 검증 → 증빙 → 평가로 추적하고 근거 없이는 PASS/CLEAR 금지.
5. 기존 Agent Codyssey MCP Core 4개 우선, 확장·보안변경 최소화. 신규 브랜치나 운영 배포는 별도 승인.

## 01~03 신규 선행 단계

- `01-requirements/`: 제2기 공식 미션 요구사항 및 평가 기준 정의
- `02-analysis/`: 과거 Round 소스·환경·증빙을 읽기 전용으로 비교 분석
- `03-design/`: 신규 미션 구조·UI/CLI/API·데이터 흐름·테스트 설계

00 계획 → 01 요구 → 02 분석 → 03 설계 → 04 신규 코드 → 05~09 검증·증빙·평가·발표·인계. 기존 코드를 신규 미션에 복사하거나 과거 PASS를 재사용하지 않습니다. 개발은 별도 승인 후 시작합니다.
